# Risiti
WhatsApp bookkeeping assistant for small shops

Risiti: a WhatsApp bookkeeping assistant for small shops.
A shopkeeper sends a voice note or text like "sold 3 sacks of flour to Mama Njeri, 4,500, M-Pesa." The bot logs the sale, replies with a clean receipt, and keeps a running ledger. At month-end it sends a summary of sales, expenses, and who still owes money.
It works because small traders already live in WhatsApp and M-Pesa and won't learn a new dashboard. Turning messy voice and text into structured entries is also something LLMs now do well.
